03 / PERMISSIONS

Read this before installing.

The current 6.0.3 manifest requests storage, alarms, and tabs, plus access to multiple Roblox and third-party hosts.

This package is not fully offline. Its manifest includes an IP address service, a Railway-hosted service, a direct IP address, Rolimons, and two localhost ports. Only install it if you understand and accept that access.

05 / FAQ

Common questions.

For setup help or release updates, use the Discord server.

Open Discord
What does Aegis change?

Supported text, images, values, and interface states displayed in your browser. It does not modify real Roblox account data.

Can other users see the preview?

No. Other people continue to see the account information supplied by Roblox.

Why is Developer mode required?

Aegis is currently distributed as an unpacked extension rather than through the Chrome Web Store.

How do I sync the preview in-game?

Open the Roblox app and stay on its Home screen, then run Aegis BootStrapper.bat from the downloaded package. The bootstrapper connects supported identity and avatar preview settings to the game client; browser-only previews work without it.

Is Aegis risk-free?

No third-party extension can be guaranteed risk-free. Review the requested permissions, inspect the package if you can, and only install it if you trust the download source.

How do I remove the changes?

Reset or disable the modules. You can also remove Aegis from your browser's Extensions page.
